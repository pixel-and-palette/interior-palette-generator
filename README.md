# Interior Palette Generator

An open-source developer utility written in Python designed to streamline design-to-code workflows for architectural visualization and interior design engines. This tool parses spatial layout metadata and structural assets to automatically isolate dominant tones, secondary values, and accent hex codes directly into exportable design formats.

## Key Features
* **Aesthetic Isolation Processing:** Automatically classifies color profiles across core design frameworks (Scandinavian, Biophilic, Mid-Century Modern, and Industrial).
* **Zero Dependencies:** Engineered completely using native Python runtime libraries for seamless integration into web services or CAD automation extensions.
* **Proportional Spatial Mapping:** Designed to account for architectural lighting conditions and furniture surface boundary distributions.

## Developer Installation

```bash
git clone https://github.com
cd interior-palette-generator
```

## Running the Processor

Execute the main script via your local terminal environment to trigger the automated spatial style extraction routine:

```bash
python palette_processor.py
```
